# 📱 Calculadora de IMC em Streamlit

Uma aplicação simples desenvolvida em Python com Streamlit para calcular o Índice de Massa Corporal (IMC).

## 🚀 Funcionalidades
- ⚖️ Cálculo automático do IMC com base no peso e na altura
- 📊 Classificação do estado nutricional (abaixo do peso, peso normal, sobrepeso, obesidade)
- ⚠️ Avisos visuais personalizados para cada faixa de IMC

## 🛠️ Tecnologias
Python | Streamlit
